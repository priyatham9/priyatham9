# Mini Claude (Family Helper)

A simple, big-text chat page for family, powered by your Anthropic API key.
The key stays on the server; the page is protected by a password.

## Deploy on Vercel (free)
1. vercel.com → Add New → Project → import this repo, set **Root Directory** to `mini-claude`.
2. Environment variables: `ANTHROPIC_API_KEY` (your key), `APP_PASSWORD` (a password for your parents).
3. Deploy, then send your parents the link and password.

Set a monthly spend limit at platform.claude.com → Settings → Limits.
